# AI-assisted development evidence

This repository makes AI-assisted engineering visible through:

* repository instructions and agent profiles under .github/;
* reusable workflow-evidence, product-quality, and AWS-delivery skills;
* reusable architecture and brownfield prompts;
* typed agent contracts and deterministic fake-agent tests;
* generated requirement, plan, design, impact, validation, security, audit, replan, and
  release artifacts;
* meaningful workstream commits created after tests and quality gates pass.

The record stores externally useful decisions and evidence only. Hidden model reasoning
and confidential assignment text are not stored.
